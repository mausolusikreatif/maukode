name: action-oriented-test-writing
description: "When asked to write tests or code, make a quick first attempt rather than exhaustive exploration first"
run_as_subagent: false
---
When the user asks you to write a test or implement code, make a reasonable first attempt within 3-5 tool calls. Only read files essential to understanding the immediate task. If uncertain about details, make reasonable assumptions and note them. Prioritize action over exhaustive exploration - the user can correct mistakes faster than you can read every file.
